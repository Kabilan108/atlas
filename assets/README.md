# Atlas logo

The logo is the approved Merge A concept: a capital A with Git branch nodes.

- `logo.svg` is the black logo for light backgrounds.
- `logo-dark.svg` is the white logo for dark backgrounds.
- `icon.svg` is the standalone black symbol.
- `logo.png` is a transparent PNG of the black logo.
- `icon.png` is a square PNG with a white background, suitable for an avatar.

The SVGs contain paths, with no font or external resource dependencies. The
wordmark uses outlined Inter Bold lettering. Keep the mark and wordmark
proportions intact when resizing.
